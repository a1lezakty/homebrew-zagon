# homebrew-zagon

Homebrew tap for [Zagon](https://github.com/a1lezakty/zagon): Jira worklogs from your Claude Code and Codex CLI sessions.

```sh
brew install a1lezakty/zagon/zagon                # CLI, macOS and Linux
brew install --cask a1lezakty/zagon/zagon         # Zagon.app (macOS menu bar)
```

The formula and the cask are published here by Zagon's release workflow. Change them in
[`packaging/homebrew/`](https://github.com/a1lezakty/zagon/tree/main/packaging/homebrew), not in this repository:
the next release overwrites them.
